# 땅파기전 기획서

> 땅을 파기 전에, 내 땅에 문화유산 관련 규제가 있는지 지도에서 바로 확인하는 서비스
>
> - 서비스 주소: https://before-digging.vercel.app
> - 저장소: https://github.com/yeonland/before-digging
> - 문서 상태: 초안 (2026-10-08)
>
> 기획 초기에는 직접 그린 임시 GeoJSON 위험구역으로 지도 클릭 판별을 만들었고, 이후 실제 공공데이터(브이월드, 국가유산청)로 교체했다.

---

## 1. 문제 정의

### 현재 상황
- 토지에서 건설공사를 하려면 그 땅이 **매장유산 유존지역**, **국가유산 지정·보호구역**, **역사문화환경 보존지역**에 해당하는지 먼저 확인해야 한다.
- 해당되면 국가유산청 협의, 국가유산영향진단(구 지표조사), 표본·시굴·발굴조사, 현상변경 허가 같은 절차가 생기고, **공사 일정과 비용이 크게 달라진다.**

### 문제
- 관련 정보가 **여러 기관 사이트에 흩어져 있다.** (국가유산청 국가유산 공간정보서비스, 브이월드, 토지이음 등)
- 토지이음 같은 공공 서비스도 정보가 복잡해서, 일반인이 읽고 판단하기 어렵다.
- 법령 용어가 어려워서 일반 토지 소유자는 **"그래서 내가 뭘 해야 하는지"** 알기 어렵다.
- 그래서 사업 계획을 세운 뒤, 또는 공사 중에 유적이 나와서야 규제를 알게 되는 경우가 생긴다.

### 해결 방향
- 지도에서 땅을 누르면 **여러 공공데이터를 한 번에 조회**해서 해당 여부를 알려준다.
- 결과는 **쉬운 말로 먼저**, 필요하면 **법령 근거와 상세 정보**를 펼쳐 볼 수 있게 한다.
- 해당되는 경우 **다음에 해야 할 일과 문의처**까지 안내한다.
- 주변에서 실제로 이뤄진 **발굴·시굴조사 이력**을 함께 보여줘서, 발굴 가능성을 판단할 근거를 준다.
- 이 정보를 합쳐 **위험도 등급**(예: 높음 / 주의 / 낮음)으로 한눈에 알려준다.

### 기획 배경
- 매장유산 관련 업무를 하면서 대상지 주변의 관련 유적을 찾아볼 일이 많았다. 그런데 공공데이터의 유적 분류가 잘못된 경우가 있어서, 결국 자료를 하나하나 직접 찾아 확인해야 했다.
- 매장유산 조사 비용은 원칙적으로 건설회사나 토지 소유자 같은 **사업시행자가 부담**하는데, 이 구조를 모른 채 사업을 시작했다가 뒤늦게 알게 되는 경우가 있다.
- 그래서 흩어진 정보를 한곳에 모으고, 토지 소유자가 **공사 전에 미리** 확인할 수 있는 서비스를 만들고자 했다.

## 2. 대상 사용자

### 데이터 한계와 위험
- **매장유산 유존지역 자체 레이어는 공개 API에 없다.** 유존지역을 정하는 근거 중 하나인 문화유적분포지도로 대신하고 있어서, 결과가 실제 유존지역과 다를 수 있다.
- 문화유적분포지도의 도형 데이터는 공식 안내에 없는 **내부 서비스 주소**에서 받는다. 주소가 바뀌면 기능이 멈출 수 있다. 이 경우에도 VWorld 결과는 계속 나오도록 만들어 두었다.
- 실제 공개 운영 전에 국가유산청 공간정보 운영팀(042-481-3177)에 **이용 방식이 괜찮은지 확인**이 필요하다.
- 데이터 출처는 화면에 표시한다. (공공누리 출처 표시 조건)

### 해발 데이터 확보 계획
- 목적: 주변 유적이 나온 해발과 내 공사의 굴착 깊이를 비교하는 정보를 준다. (예: 지하 1층 주차장만 파는 공사는 유적층에 닿지 않을 수 있음) 법정 기준이 아니라 **비교 정보**로만 보여준다.
- 해외 무료 고도 API(SRTM, ASTER 30m)는 같은 지점에서 6~10m씩 차이가 나서 유적층 비교용으로는 쓸 수 없다.
- [ ] 국토정보플랫폼(map.ngii.go.kr) 공개DEM 해상도와 형식 확인 (대용량 전송 프로그램 설치 문제로 보류 중)
- [ ] 시범 지역 1곳 선정
- [ ] 시범 지역 수치지형도 DXF(1:5,000, 등고선·표고점) 다운로드
- [ ] QGIS로 DEM 제작: 좌표계 지정 → 등고선·표고점 추출 → Z값 추출 → TIN 보간 → GeoTIFF(EPSG:4326) 내보내기
- [ ] `/api/elevation`으로 좌표별 해발 조회, 결과에 "참고용 추정값" 표시
- [ ] 시범 지역 주변 유적의 유구 해발을 보고서에서 수동 정리
- [ ] 국가유산 공간정보서비스 「매장문화재 원문정보」와 보고서 연결 가능 여부 확인

## 5. 법·제도 근거

> 서비스는 **참고용 정보**를 제공하며, 법적 판단을 대신하지 않는다. 화면에도 이 문구를 표시한다.

### 확인된 내용 (2026-10-08 조문 확인)

> 법령 위키(nepla.ai, follaw.co.kr)의 현행본 조문으로 확인했다. 화면에 넣기 전 국가법령정보센터에서 최종 확인한다.

**① 국가유산영향진단 (예전 지표조사) — 「국가유산영향진단법」 (시행 2025.2.14.)**
| 근거 | 내용 |
|---|---|
| 법 제9조제1항 | 건설공사 시행자는 아래에 해당하면 **사업계획 수립 완료 전에** 영향진단을 실시해야 한다 |
| 법 제9조제1항제1호 + 시행령 제5조제1항 | 토지·내수면·연안 건설공사로 사업 면적 **3만㎡ 이상** (유존지역과 국가·지자체가 지표조사한 지역 면적은 빼고 계산). 내수면·연안 골재 채취는 15만㎡ 이상. 같은 목적으로 나누거나 붙여서 개발하면 전체 면적으로 판단 |
| 법 제9조제1항제2호 | **매장유산 유존지역에서 시행하는 건설공사 → 면적과 상관없이 대상** |
| 법 제9조제1항제3호 + 시행령 제5조제2항 | 3만㎡ 미만이어도 과거 매장유산 출토·발견 지역 등으로 시장·군수·구청장이 고시한 구역의 건설공사 |

|---|---|

## 7. 기술 구조

```
브라우저 (index.html, Leaflet)
   │
   ├─ /api/vworld          → VWorld WMS (지적도, 국가유산 구역 이미지)
   ├─ /api/parcel          → VWorld 연속지적도 + 국가유산 구역 + 국가유산청 WFS (필지 단위 진단, 겹친 면적 계산)
   ├─ /api/heritage        → VWorld 2D 데이터 API + 국가유산청 WFS (지적도에 없는 곳의 클릭 지점 진단)
   └─ /api/heritage-sites  → 국가유산청 WFS (줌 15 타일 단위 유적 도형, 캐시)
         │
   Vercel 서버리스 함수 (서울 리전 icn1)
```
- **API 키 보호**: VWorld 키는 Vercel 환경변수에만 두고, 브라우저는 서버 프록시를 거쳐서만 요청한다.
- **서울 리전 고정**: VWorld가 해외(미국 기본 리전)에서 오는 요청을 끊어서 `vercel.json`으로 서울 리전에 고정했다.
- **캐시**: 공공데이터 응답은 CDN에 하루 동안 캐시해서 외부 서버 부담과 응답 시간을 줄인다.
- **겹친 면적 계산**: Turf.js로 필지와 각 구역의 교집합 면적을 계산한다. 10㎡ 미만 겹침은 지적도와 구역도의 도면 오차일 수 있어 "경계에만 걸침"으로 따로 표시하고 전체 면적에서 뺀다.
- **배포**: GitHub `main` 브랜치에 푸시하면 Vercel이 자동으로 배포한다.
